# keycat PoC

타이핑으로 농사짓는 맥 오버레이 위젯 **keycat**의 기술 검증(PoC). 오버레이 상시 표시와 전역 타자 카운트라는 두 핵심 리스크 검증에서 출발해, 지금은 씨앗 구매 → 파종 → 급수 → 성장 → 수확 → 판매로 이어지는 농장 루프와 고양이 수집 요소까지 갖춘 상태다.

1. 풀스크린 포함 어디서든 항상 위에 떠 있는 투명 오버레이 창
2. 다른 앱에서 친 키까지 세는 전역 타자 카운트 + 필요한 권한 확인

요구 사항: macOS 14 이상 (메뉴 badge/섹션 헤더 API 사용).

## 실행

```sh
swift run
```

- Dock에 아이콘이 안 뜨고 메뉴바에 🐾 아이콘이 뜬다.
- 우측 상단에 오버레이 창이 나타난다. 축소(작은 위젯)/확장(농장 콘솔)은 오버레이 안의 버튼으로 전환.
- 첫 실행 시 **입력 모니터링(Input Monitoring) 권한** 요청이 뜬다.
  시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 허용하면,
  앱이 폴링으로 자동 감지해 카운트를 시작한다(재시작 불필요).

## PoC 검증 체크리스트

**오버레이 창**
- [ ] 다른 앱을 클릭해도 창이 항상 위에 유지된다
- [ ] 풀스크린 앱(예: 풀스크린 Safari) 위에서도 보인다
- [ ] Spaces(데스크톱) 전환 시 따라온다
- [ ] 창 배경을 드래그해 이동할 수 있다

**전역 키 카운트**
- [ ] 요청되는 권한이 "입력 모니터링"인지 "손쉬운 사용"인지 확인 (실기기 기준)
- [ ] 권한 허용 후 **다른 앱**(메모/브라우저)에서 타이핑하면 숫자가 오른다
- [ ] 권한 거부 상태에서도 앱이 죽지 않고 안내 문구를 띄운다

**성능**
- [ ] idle 상태에서 CPU가 거의 0%다 (활성 상태 보기)

## 확장 화면 (농장 콘솔)

밭 잔디는 짙은 잔디/꽃 잔디를 **랜덤 배치**하고, 그 배치와 칸별 상태를
`~/Library/Application Support/KeyCat/farm.json`(8열×12행)에 저장해 재실행 후에도 복원한다.

**코인**: 타이핑 10회당 1코인이 자동 지급되고, 수확한 작물을 창고에서 판매하면 판매가만큼 추가로 쌓인다.

**밭 상태 흐름**: 빈 칸(마른 땅) 탭 → 씨앗 선택 후 파종 → 고양이가 이동해 급수 → 일정 시간 성장 → 수확 가능 상태가 되면 고양이가 수확해 창고에 적립. 수확 시 확률적으로 새 고양이가 드랍된다(당근: cheese 20% · oddeye 0.1%, 양배추: gray 20%, 이미 보유한 고양이는 대상에서 제외).

**오토 모드**(⌘A 또는 확장 화면 버튼): 켜두면 빈 밭에 보유 씨앗을 자동으로 순서대로 파종하고, 급수·수확도 고양이가 알아서 처리한다. 심을 씨앗이 떨어지면 고양이가 밭 한쪽의 고양이 집으로 이동해 "씨앗 부족" 표시를 띄운다. 오버레이 창을 숨기거나 축소해도 진행 중이던 작업은 백그라운드에서 계속 완료된다.

하단 탭(상점/창고/도감/기록)은 모두 실제 기능이 구현되어 있다.
- **상점**: 씨앗(당근 5코인 · 양배추 15코인)과 고양이(샴 · 스핑크스, 각 10,000코인)를 구매. 수량 선택 시 보유 코인 기준 최대 구매 가능 수량으로 채워주는 MAX 버튼 제공.
- **창고**: 보유 씨앗 전량과, 보유 중인 작물을 판매. 수량 선택 시 보유 수량 전체를 채워주는 MAX 버튼 제공.
- **도감**: 작물/고양이 목록. 고양이 항목을 누르면 보유 여부와 드랍 확률을 확인하고, 보유한 고양이로 밭에서 일하는 고양이를 바꿀 수 있다.
- **기록**: 이번 달 날짜별 타자 수를 잔디 히트맵으로 보여주고, 연속 기록일과 이번 달 누적 타자 수를 표시. 날짜를 누르면 해당 일자 타자 수 상세를 확인할 수 있다.

## 구조 (`Sources/KeyCat/`)

- `main.swift` - NSApplication을 .accessory(메뉴바 상주)로 실행
- `AppDelegate.swift` - 메뉴바 제어바 메뉴, 오버레이 NSPanel 설정, 축소/확장, 코인 지급 배선
- `KeyCounter.swift` - CGEventTap 기반 전역 keyDown 카운터 + 권한 처리 + 일시 정지 + 일자별 타자 기록 저장 + 코인 지급 트리거
- `OverlayView.swift` - SwiftUI 오버레이 UI (RHODES 콘솔 테마, 축소/확장 화면, 하단 탭 전환, 상점/창고/도감/기록 팝업)
- `CatSprite.swift` - 고양이 스프라이트 시트/모션(배회 + 급수·수확 작업 수행), 잔디 타일 렌더링(`groundTile`, `GrassBackground`, `FarmFieldGrassView`)
- `FarmField.swift` - 밭 그리드 데이터 모델(`FarmFieldData`, `FieldTile`, 파종~수확 상태 머신 `FieldTileState`, 작업 큐 `FarmWorkTask`)과 `farm.json` 로드/저장(`FarmFieldStorage`)
- `Theme.swift` - 색/테마 유틸
- `AppState.swift` - 축소/확장, 코인/씨앗/작물 인벤토리, 구매·판매, 파종·급수·성장·수확 상태 머신, 고양이 언락/드랍, 자동 모드, 밭 상태(`farmField`) 보관을 담당하는 게임 로직 중심 클래스

## 알려진 PoC 한계

- `swift run`으로 돌리면 권한이 실행 바이너리(또는 터미널)에 귀속된다. 정식 배포 시엔 `.app` 번들 + 코드 서명으로 바뀐다.
- App Store 배포는 샌드박스 정책상 전역 키 감지가 막혀 불가. 웹(직접 배포, 공증)이 전제.
