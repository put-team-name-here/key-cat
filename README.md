# typing-farm PoC

타이핑으로 농사짓는 맥 오버레이 위젯의 **기술 검증(PoC)**. 그래픽은 전부 회색/단색 박스 플레이스홀더이며, 목적은 아래 두 리스크가 실제로 되는지 확인하는 것.

1. 풀스크린 포함 어디서든 항상 위에 떠 있는 투명 오버레이 창
2. 다른 앱에서 친 키까지 세는 전역 타자 카운트 + 필요한 권한 확인

## 실행

```sh
swift run
```

- Dock에 아이콘이 안 뜨고 메뉴바에 🐾 아이콘이 뜬다.
- 우측 상단에 오버레이 창이 나타난다.
- 첫 실행 시 **입력 모니터링(Input Monitoring) 권한** 요청이 뜬다.
  시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 허용하면,
  앱이 폴링으로 자동 감지해 카운트를 시작한다(재시작 불필요).

메뉴바 아이콘에서 `축소/확장`, `표시/숨김`, `종료` 가능.

## PoC 검증 체크리스트

**오버레이 창**
- [ ] 다른 앱을 클릭해도 창이 항상 위에 유지된다
- [ ] 풀스크린 앱(예: 풀스크린 Safari) 위에서도 보인다
- [ ] Spaces(데스크톱) 전환 시 따라온다
- [ ] 창 배경을 드래그해 이동할 수 있다

**전역 키 카운트**
- [ ] 요청되는 권한이 "입력 모니터링"인지 "손쉬운 사용"인지 확인 (실기기 기준)
- [ ] 권한 허용 후 **다른 앱**(메모/브라우저)에서 타이핑하면 숫자가 오른다
- [ ] 권한 거부 상태에서도 앱이 죽지 않고 안내 문구를 띄운다

**성능**
- [ ] idle 상태에서 CPU가 거의 0%다 (활성 상태 보기)

## 구조

- `main.swift` - NSApplication을 .accessory(메뉴바 상주)로 실행
- `AppDelegate.swift` - 메뉴바 아이템, 오버레이 NSPanel 설정, 축소/확장
- `KeyCounter.swift` - CGEventTap 기반 전역 keyDown 카운터 + 권한 처리
- `OverlayView.swift` - SwiftUI 오버레이 UI (플레이스홀더)
- `AppState.swift` - 축소/확장 상태

## 알려진 PoC 한계

- `swift run`으로 돌리면 권한이 실행 바이너리(또는 터미널)에 귀속된다. 정식 배포 시엔 `.app` 번들 + 코드 서명으로 바뀐다.
- App Store 배포는 샌드박스 정책상 전역 키 감지가 막혀 불가. 웹(직접 배포, 공증)이 전제.
