## 무엇을 만드는가
keycat(구 keyboard-game)은 타이핑으로 농사짓는 macOS 메뉴바 오버레이 앱(Swift/SwiftUI, `Sources/KeyCat/`). 확장 화면(농장 콘솔)의 밭 배경이 기존엔 `(r + c) % 2 == 0` 체커보드로 잔디/꽃잔디를 고정 배치했는데, 이번 세션에서 **랜덤 배치 + 파일 영속화**로 바꿨다. 앱 재실행해도 같은 배치가 유지되고, 앞으로 작물 심기 등 밭 상태 변경도 같은 파일에 누적하는 구조로 설계했다.

## 이번 세션에서 확정한 결정 (중요) - 타일 배치 방식

기존: `CatSprite.swift`의 `GrassBackground`가 뷰 크기를 `tileSize`로 나눠 동적으로 행/열을 계산하고, `(r+c)%2` 체커보드로 잔디 종류를 그때그때 계산해서 그렸다(상태 저장 없음).

새 방식: 사용자에게 3가지를 직접 물어서 결정함(추측으로 만들지 않음).
1. **저장 위치**: `~/Library/Application Support/KeyCat/farm.json` (앱 쓰기 가능한 데이터 폴더). 번들 리소스가 아니라 런타임에 읽고 쓰는 세이브 파일.
2. **그리드 크기**: **고정 8열 x 12행** (기존 확장 화면 360x540 / tileSize 45 로 실제 계산되던 값과 동일). 화면 크기에 따른 동적 계산은 버림.
3. **밭 상태 범위**: 이번엔 **스키마만** 설계. 칸마다 `grass`(잔디 종류) + `state`(현재는 `empty` 케이스만) 를 갖는 정도로 최소화하고, 작물 심기/성장 로직은 아직 구현 안 함(다음 확장 시 `FieldTileState`에 케이스만 추가하면 됨).

파일이 없으면 최초 실행 시 랜덤 배치(각 칸 `Bool.random()`으로 normal/flower 결정)를 만들어 즉시 저장하고, 이후엔 파일을 그대로 읽어 복원한다. `AppState.farmField`가 바뀔 때마다 `didSet`에서 자동 저장.

**검증한 사실** (실제 빌드+실행으로 확인, 추측 아님):
- `swift build` 성공.
- 앱을 짧게 실행 -> `farm.json`이 96칸(8x12)으로 생성됨, 이번 실행에서 normal 47 / flower 49로 분포.
- 같은 파일로 앱을 다시 실행 -> `farm.json`의 md5가 동일 (배치가 그대로 유지됨, 재생성 안 됨).

## 재사용할 코어 / 건드리지 말 것
- `Sources/KeyCat/FarmField.swift` (신규) - `GrassKind`(normal/flower, `imageName` 매핑), `FieldTileState`(현재 `empty`만), `FieldTile`, `FarmFieldData`(`cols=8`, `rows=12` static, `tiles: [FieldTile]` row-major, `randomLayout()`), `FarmFieldStorage`(`load()`/`save()`, Application Support 경로 계산). **밭 상태를 확장할 땐 이 파일의 타입에 케이스/필드만 추가**하고 스토리지 로직은 그대로 재사용.
- `Sources/KeyCat/CatSprite.swift` - `groundTile(_:)` 로 잔디 PNG 렌더링 공용 헬퍼를 뽑아냄. 축소 화면(고양이 박스) `GrassBackground`는 **일부러 그대로 둠**(체커보드 유지, 밭이 아니라 장식용이라 스코프 밖). 밭 전용 렌더러는 새로 추가한 `FarmFieldGrassView(field:tileSize:)` - `FarmFieldData.rows/cols` 기준으로 고정 그리드를 그림.
- `Sources/KeyCat/AppState.swift` - `@Published var farmField: FarmFieldData` 추가, `didSet`에서 `FarmFieldStorage.save()` 호출. 초기값은 `init()`에서 `FarmFieldStorage.load()`.
- `Sources/KeyCat/OverlayView.swift:247` 부근 `farmField` 뷰 - `GrassBackground(tileSize: 45)` -> `FarmFieldGrassView(field: state.farmField)` 로 교체 완료.
