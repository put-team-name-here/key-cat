## 현재 UI 구조 (축소화면 구현에 필요한 사실)
- `Sources/KeyCat/AppDelegate.swift`
  - `OverlayPanel`(borderless NSPanel, canBecomeKey), `.floating`, `[.canJoinAllSpaces, .fullScreenAuxiliary]`, 우측 상단 배치
  - 크기: 축소 230x230 / 확장 405x838, `toggleSize()`가 우측상단 모서리 고정한 채 애니메이션 전환
  - NSMenu 제어바: 농장 표시/숨김(⌘F), 정보 3항목(기록한 글자/보유 코인/수확 가능 여부, `menuNeedsUpdate`에서 badge 갱신), 설정 섹션(기록 일시 정지 ⌘P, 프로그램 종료 ⌘Q 빨강)
- `Sources/KeyCat/OverlayView.swift` - RHODES 콘솔 테마(`Theme.rhodes`), `state.expanded`로 두 화면 전환
  - **`collapsedView`(축소 화면, 현재 전부 플레이스홀더)**: logoHeader(compact) + 고양이 캐릭터 자리(placeholderBox 62h) + statTile("오늘 타자 수"=`counter.count`) + statusMessage(권한 안내) + 우상단 확대 iconButton
  - `expandedView`: 헤더/farmArea(말풍선+고양이+3x4 밭 그리드)/currencyRow/shopPreview/bottomTabs - 역시 플레이스홀더 수준
  - 재사용 가능한 조각 뷰: `statTile`, `iconButton`, `placeholderBox`, `logoMark`, `CutCorner`(Theme.swift)
- `Sources/KeyCat/Theme.swift` - `Color(hex:)`, RHODES 팔레트, CutCorner 셰이프
- 데이터 흐름: `KeyCounter`(count, permissionGranted, isPaused/togglePause - CGEventTap enable 토글) / `AppState`(expanded, coins=0, harvestAvailable=false - 코인·수확 시스템은 **미구현 자리표시**)
